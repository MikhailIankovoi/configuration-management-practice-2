# Визуализатор зависимостей пакетов Alpine Linux

Практическая работа №2 по дисциплине
«Конфигурационное управление».

Вариант 29.

## Описание

Программа предназначена для построения и визуализации
графа зависимостей программных пакетов Alpine Linux.

Проект разрабатывается на Python и предусматривает:
- Чтение конфигурации из YAML-файла.
- Получение зависимостей пакетов из APK-репозитория.
- Построение графа зависимостей с помощью рекурсивного BFS.
- Поиск обратных зависимостей.
- Тестовый режим с локальным описанием графа.
- Формирование диаграммы в формате Mermaid.

## Текущая реализация

Этап 1 — CLI-прототип:
- Загрузка конфигурации из файла config.yaml.
- Проверка корректности параметров.
- Обработка ошибок конфигурации.
- Вывод параметров в консоль.

Остальные этапы находятся в разработке.

## Требования

- Python 3.10 или новее.
- Библиотека PyYAML.

## Установка

Клонировать репозиторий:

git clone https://github.com/MikhailIankovoi/configuration-management-practice-2.git

Перейти в папку проекта:

cd configuration-management-practice-2

Установить зависимости:

py -m pip install -r requirements.txt

## Настройка

Программа использует файл config.yaml.

Пример конфигурации:

    package_name: busybox
    version: "1.37.0-r0"
    repository: "https://dl-cdn.alpinelinux.org/alpine/latest-stable/main/x86_64"
    test_mode: false

Параметры:

- package_name — название исследуемого пакета.
- version — версия пакета.
- repository — URL репозитория или путь к тестовому файлу.
- test_mode — включение тестового режима (true/false).

Тестовый режим будет реализован на третьем этапе.

## Запуск

На Windows:

    .\run.bat

Либо напрямую через Python:

    py src/main.py

## Пример вывода

    Конфигурация визуализатора зависимостей:
    package_name: busybox
    version: 1.37.0-r0
    repository: https://dl-cdn.alpinelinux.org/alpine/latest-stable/main/x86_64
    test_mode: False

При некорректных параметрах программа выводит
сообщение с описанием ошибки.

## Тестирование

Для автоматической проверки программы используется
встроенный модуль Python unittest.

Запуск всех тестов:

    py -m unittest discover -s tests -v

Тесты проверяют:
- Загрузку корректной конфигурации.
- Отсутствие обязательных параметров или пустые значения.
- Некорректный URL репозитория.
- Неправильный тип тестового режима.
- Отсутствие конфигурационного файла.
- Ошибки синтаксиса YAML.
- Наличие и отсутствие тестового репозитория.

## Структура проекта

- src/main.py — точка входа в программу.
- src/config.py — загрузка и проверка конфигурации.
- config.yaml — настройки приложения.
- requirements.txt — зависимости Python.
- run.bat — сценарий запуска на Windows.
- tests/test_config.py — тестирование конфигурации.
